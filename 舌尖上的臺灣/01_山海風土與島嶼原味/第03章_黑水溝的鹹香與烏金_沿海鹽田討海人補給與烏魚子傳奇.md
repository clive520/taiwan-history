# 第 03 章 黑水溝的鹹香與烏金——沿海鹽田、討海人補給與烏魚子傳奇

> **文庫導讀**：  
> 在橫渡臺灣海峽「黑水溝」的浩瀚狂濤中，先民口中咀嚼的不是山珍海味，而是一撮粗糲的日曬海鹽、幾片乾硬發黑的鹹魚乾，以及一碗被滾燙開水沖開的冷飯。這股深邃、剛烈、近乎苦澀的「鹹」，是三百年來臺灣移民在死亡邊緣掙扎求生的生理底色。  
> 然而，同樣是這片充滿未知與凶險的海域，每逢冬至前後，卻會伴隨著強勁呼嘯的東北季風，送來大自然最慷慨的饋贈——成群結隊、腹藏豐腴卵黃的「信魚」野生烏魚。從明代陳第筆下的「以其子鹽醃日乾，號為烏魚子」，到明鄭陳永華於臺南瀨口開創「瓦盤天日曬鹽」，臺灣先民以無與倫比的匠心，將海水的粗鹽、東北季風的呼嘯、冬陽的溫潤與花崗岩的重壓融為一體，淬鍊出如落日般耀眼通透的「烏金」琥珀。這是一部以汗水為結晶、以海浪為節拍的島嶼鹹味史詩。

## 🌊 引言：波濤深處的鹹澀與金色希望

十七世紀末的一個冬夜，狂烈的東北季風正以排山倒海之勢撕扯著臺灣海峽的海面。

一艘由廈門開往大員的雙桅紅頭木艚船，正航行在令人聞之色變的「黑水溝」（澎湖水道）中心。海水深不見底，呈墨黑色的浪峰一次次砸向傾斜的木質船舷。船艙深處，十幾名蜷縮在麻布袋之間的漢人移民與水手，臉色慘白、骨瘦如柴。在劇烈的顛簸與刺鼻的嘔吐物氣味中，船老大端出了一個粗陶大碗——裡面是冷透的剩飯，泡著滾水，上面僅僅鋪了幾根深褐色的老鹹菜乾與一小塊硬如木炭的鹽漬巴浪魚。

水手們用滿布老繭的手抓起飯粒與鹹魚，大口吞嚥，連一滴渾濁的鹹湯也不願浪費。

那一刻，舌尖感受到的不是精緻烹飪的愉悅，而是一種純粹、野蠻、高濃度的**「鹽的燃燒」**。在水汽瀰漫、狂風呼嘯的海上，高濃度的氯化鈉與乾燥魚肉的游離氨基酸，是人體抵抗脫水、維持神經傳導、在死亡邊緣重新點燃肌肉力量的唯一生理防線。

然而，當這艘千瘡百孔的木船終於穿過黑水溝，駛入臺南大員港（安平）平靜的內海沙洲時，清晨的陽光破開雲層，眼前展現的卻是另一幅令人屏息的奇景：
沿海數十座鹽田如明鏡般映照著蔚藍天空，一排排竹篙棚架在海風中整齊延展。棚架上，鋪滿了數以千計、透著金紅光芒的卵形物件——那是剛剛經過重石加壓、正在吸收冬日陽光的野生**「烏魚子」**。

從黑水溝生死未卜的「鹹苦生存」，到鹽灘竹棚上璀璨如黃金的「鹹鮮極品」，這片海域在數百年間，見證了臺灣人如何以鹽為刀、以風為曲，把最殘酷的海洋險阻，轉化為島嶼最頂級的風土滋味。

## 🛶 第一幕：橫渡黑水溝——討海羅漢腳的「鹹水命」與生理補給

### 1. 「十去六死三回頭」的海洋險境
在清代文獻中，臺灣海峽被稱為「落漈」或「黑水溝」。澎湖與臺灣本島之間的水道，水色墨黑如鐵，流速極快，暗流如漩渦。《臺灣府志》形容其：「海流最險，舟行其間，呼吸存亡。」

對早期乘著木帆船橫渡海峽的漢人移民（羅漢腳）與討海漁民而言，每一次出海都是一場向天借命的豪賭。在長達數日乃至數週的航程中，淡水極難保存，木桶內的淡水往往在一週後便長出綠藻、發出惡臭。

此時，食物不僅僅是充飢的能量來源，更是一套嚴密的**海洋生存防護機制**：
- **鹽漬鹹魚乾（鹹巴浪、鹹鯖魚）**：透過極致的高鹽醃漬，將魚肉的水分活度（Water Activity, $a_w$）降至 0.70 以下，使絕大多數腐敗菌與致病菌無法繁殖；
- **番薯籤（地瓜籤）**：閩南鄉間曬乾的番薯刨絲，極耐儲存且體積輕巧，入水即能煮成濃稠澱粉糊，提供高熱量與膳食纖維；
- **鹹水泡飯（菜脯滾水泡冷飯）**：水手劇烈划槳搖櫓，體內鈉離子大量隨汗液流失。若僅飲用淡水，極易引發低鈉血症（水中毒），導致肌肉痙攣、昏迷。一碗鹹菜乾配滾水泡冷飯，能在五分鐘內迅速平衡體液滲透壓，補充鈉、鉀與葡萄糖。

這種粗礪、直接、強烈的鹹味，深深刻進了早期移民的骨髓，也奠定了臺灣西南部沿海料理崇尚「鹹香厚重、原汁逼味」的底層風格。

## 🧂 第二幕：白金的誕生——陳永華與瀨口瓦盤鹽田的技術革命

### 1. 從「煮海為鹽」到「天日曬鹽」
在荷蘭統治時期，儘管平原上蔗糖與鹿皮貿易如火如荼，但島上的食用鹽卻長期處於匱乏狀態。居民多在海邊掘坑引水，使用鐵鼎或大鐵鍋日夜砍柴煎熬，稱為「煎鹽法」。煎鹽法不僅消耗大量柴火，且熬出的粗鹽含有大量苦澀的氯化鎂（苦滷）與硫酸鈣，顆粒發灰，口感苦澀。

1665 年（明永曆十九年），鄭成功部將、諮議參軍**陳永華**巡視臺南沿海，深感軍民食鹽仰賴走私非長久之計，更阻礙民生。他觀察到西南沿海日照強烈、秋冬雨水稀少，極具天然日曬潛力，遂在臺南瀨口（今臺南市南區日新溪一帶）開創了臺灣歷史上第一座正規的**「天日曬鹽場」**。

### 2. 瓦盤鹽田的流體力學與熱力學智慧
陳永華推行的並非普通的土盤曬鹽，而是極具巧思的**「瓦盤鹽田」**：
- **碎瓦鋪底**：鹽工將民間打破的紅瓦盆、紅磚碗片敲碎，一片片手工緊密鑲嵌在結晶池泥土表面，縫隙再以黏土填實壓平；
- **瓦盤的三重科技優勢**：
  1. **熱傳導倍增**：紅瓦片比熱小、吸熱快，在烈日曝曬下能將底層水溫迅速提高 3℃~5℃，加速水分蒸發；
  2. **隔絕泥質污染**：瓦片徹底阻斷了下層黑色黏土與海鹽結晶的接觸，產出的海鹽潔白如雪、晶瑩純淨；
  3. **便於採收刮鹽**：光滑的瓦片表面讓鹽工使用木刮板收鹽時，不會刮起泥沙，鹽粒完整整齊。

#### 曬鹽的三段式生化提純：
1. **蒸發池（大中小水）**：天然海水引進後，波美度由 3°Be 緩慢濃縮至 15°Be，此時海水中的碳酸鈣（雜質）率先沉澱析出；
2. **滷缸（淋滷濃縮）**：將高濃度鹽水導入貯滷池，波美度提升至 20°~24°Be，硫酸鈣相繼沉澱分離；
3. **結晶池（瓦盤）**：當波美度精準達到 **25°Be 至 29°Be** 的極限區間時，純淨的氯化鈉（NaCl）開始呈等軸晶系在瓦片上如霜花般綻放；一旦超過 30°Be，鹽工便會立即將剩餘的「苦滷」（富含氯化鎂與硫酸鎂）排出，防止苦澀物質混入鹽粒。

這套由陳永華開創的精準鹽析技術，不僅使明鄭政權實現了食鹽自主，更孕育了後來七股、北門、布袋綿延數百里的雪白「鹽田帝國」，為臺灣海產醃漬與烏魚子加工提供了最純淨的物質基石。

## 🐟 第三幕：冬至的信魚風暴——黑潮支流上的「烏金傳奇」

### 1. 守約而來的「信魚」
若說海鹽是土地與太陽的產物，那麼**烏魚（*Mugil cephalus*，鯔魚）**則是季風與大洋的恩賜。

在臺灣海產歷史中，沒有任何一種魚類像烏魚一樣，擁有如此神聖的「契約性」。每年立冬之後，隨著西伯利亞高壓增強，強烈的東北季風將中國北方沿岸的冷水團往南推擠。棲息於長江口以北的大批成熟烏魚群，為了尋找適當的產卵環境，沿著臺灣海峽水溫較高的黑潮支流向南洄游。

這群魚沿著臺灣西部海岸線疾游，每年的行蹤精準得令人敬畏：
- **大雪至冬至前一週**：魚群抵達苗栗通霄、臺中梧棲、彰化鹿港海域，此時魚卵尚在發育，俗稱「正頭烏」；
- **冬至前後十天**：魚群集結於**臺南安平、高雄茄萣至屏東枋寮**一帶海面。此時海水溫度恰好維持在 20℃~22℃ 之間，烏魚體內的卵巢發育達到最鼎盛階段，油脂含量最高、卵黃飽滿如熟透果實；
- **冬至過後**：魚群在西南外海產卵完畢，沿著外洋逆流北返，身軀消瘦乾癟，肉質柴澀，卵巢空空如也，俗稱「回頭烏」。

因為牠年年冬至如期抵達，數百年來臺灣討海人尊其為**「信魚」**——牠從不失信於討海人。

### 2. 荷蘭東印度公司的「烏魚旗稅」與安平盛況
早在 1640 年代，荷蘭大員長官便在《熱蘭遮城日記》中詳細記錄了冬至捕烏的盛況：
每年十一月，來自福建漳州、泉州以及臺灣本土的戎克漁船，數百艘聚集於大員港外。VOC 當局向每艘漁船徵收白銀 1 至 2 個里爾，發給一面紅色或白色的**「烏魚旗（vaantjes）」**，插在桅杆上作為合法作業憑證。

當時的安平港灣，整整兩個月不分晝夜燈火通明。碼頭兩側搭滿了竹木臨時工寮，漁民捕獲烏魚靠岸後，岸上的婦孺立即進行流水線作業：
- **公魚**取下白子（烏魚膘），肉質鮮嫩留作煮湯；
- **母魚**小心翼翼剖出兩片金黃飽滿的卵囊；
- **魚身**抹上厚厚粗鹽，生曬為鹹烏魚乾，堆積如山裝入木桶，外銷至長崎出島與福建廈門；
- **魚子**則進入最精密的鹽漬風乾程序，成為身價百倍的「黑金（烏金）」。

## 💎 第四幕：六道微米煉金術——血線、重石、海風與日光琥珀

一片完美的野生烏魚子，絕非簡單的曬魚卵，而是一場結合了流體力學、膠體化學與紫外線熟成的微米級分子料理實驗。傳統安平與鹿港的老匠人，恪守著六道不可逾越的嚴格工序：

```text
┌─────────────────────────────────────────────────────────────┐
│                 野生烏魚子傳統六道工藝流程                  │
├─────────────┬───────────────────────────────────────────────┤
│ 1. 剖腹綁頭 │ 保留肉頭，雙向棉繩緊密纏結，防止油脂外溢     │
│ 2. 排血純化 │ 針刺微血管，硬幣柔和推擠刮除黑血，冷鹽水洗滌  │
│ 3. 粗鹽滲透 │ 均勻鋪撒海鹽，利用高滲透壓抽離 30% 游離水     │
│ 4. 脫鹽平滑 │ 清水短暫淨化，軟毛刷拂平表面，平衡表層鹽度   │
│ 5. 板壓成型 │ 杉木夾板，層疊花崗岩壓石，每日加壓促進膠凝   │
│ 6. 天日風乾 │ 迎向東北季風與冬陽，定時翻面，催化酯化與琥珀色│
└─────────────┴───────────────────────────────────────────────┘
```

### 1. 剖腹綁頭：保護神聖的完整囊袋
熟練的魚師手持鋒利的剖魚小刀，沿著烏魚腹部中線輕巧劃開，深度必須控制在毫米級，絕不能刺破卵膜，更嚴禁劃破膽囊。取出卵囊時，必須刻意在頂端連帶切下一小片腹部肌腱肉（俗稱「肉頭」）。這塊肉頭隨後用天然棉線以八字結緊緊捆綁，確保卵巢內部微細血管中的油脂與卵黃蛋白質在後續壓製時不會從開口處噴濺外漏。

### 2. 排血純化：決定透明度與純淨度的關鍵
新鮮卵囊表面密布著微細血管網。若殘留血液，日曬後鐵離子氧化會使魚子表面發黑，並帶有難聞的血腥鐵鏽味。
匠人會手持縫衣細針，沿著微血管輕輕點刺數個微孔，再用一枚光滑的五分硬幣或小瓷湯匙，以柔和均勻的力道順著血管方向一點點將黑血推擠擠出，最後浸入 5℃ 左右的冷淡鹽水中徹底漂洗。完成排血後的卵囊，呈現出純淨均勻的橙黃色半透明狀態。

### 3. 粗鹽滲透與重石冷壓：膠體結構的重新排列
將洗淨的卵囊平鋪於木板上，均勻撒上臺南瀨口出產的粗粒海鹽，靜置醃漬 60 至 90 分鐘。高濃度的鈉離子在卵膜內外形成巨大的滲透壓梯度，將卵細胞深層的自由水迅速抽離，使卵黃球初步脫水凝固。

洗去殘鹽後，最考驗匠人功力的「壓石整型」登場：
卵囊一對對平鋪在厚實的杉木板上，覆上壓板。上方放置重達數十公斤的花崗岩壓石。最初兩天壓力較輕，使魚子均勻攤平成厚度約 1.5 公分的長橢圓形；隨著水分蒸發，逐日增加石塊重量。在持續而溫和的機械重壓下，原本鬆散球狀的卵黃顆粒破裂融合，蛋白質與脂質重新交聯，轉變成質地緊實、密不透風的凝膠基質。

### 4. 冬陽與季風的慢熟成：分子層級的風味轉化
最後的昇華在竹篙棚架上完成。
臺灣西南沿海冬季特有的氣候——**「陽光強、濕度低、東北季風乾燥呼嘯」**，是全世界最完美的天然熟成室。
在連續 7 至 10 天的日曬與風乾過程中，魚子內部的生化反應悄然發生：
- **紫外線的光催化作用**：使卵黃中的胡蘿蔔素與葉黃素分子結構微調，色澤從初期的鮮黃，逐漸轉變為深邃透光、宛如凝固黃昏的**橙紅琥珀色**；
- **內源性蛋白酶的水解作用**：蛋白質長鏈緩慢分解為短肽與游離氨基酸，其中**谷氨酸（鮮味）**與**甘胺酸（甜味）**的濃度倍增；
- **脂質的溫和氧化**：豐富的不飽和脂肪酸在空氣與陽光觸媒下，生成微量具有堅果香、奶油香與海洋氣息的揮發性醛酮化合物。

當匠人用拇指指腹輕輕按壓魚子中央，感覺質地「軟硬適中，如按壓耳垂般富有彈性，且不留指印」時，這件歷經冰冷海水、烈火石磨、高壓巨石與海風冬陽洗禮的大地藝術品，終於大功告成。

## 🍽️ 第五幕：從浪尖粗食到國宴傳奇——臺灣鹹味哲學與土地記憶

從 17 世紀黑水溝上一碗充飢續命的「鹹水冷飯」，到 21 世紀米其林星級餐桌上炭火微烤、配以薄切白蘿蔔與青蒜苗的「極品野生烏魚子」，臺灣人對「鹹」與「鮮」的理解，經歷了一場長達四百年的美學涅槃。

在貧困匱乏的拓荒年代，「鹽」是抵抗腐敗、征服海洋、對抗疾病的殘酷盔甲。先民在最凶險的波濤中，依靠高濃度的鹽分鎖住獵獲、保全性命。然而，臺灣人並沒有止步於單純的生存。他們利用大自然最嚴苛的要素——刺骨呼嘯的東北季風、灼熱焦乾的冬日豔陽、拍擊沙洲的海水浪花，發明了瓦盤天日曬鹽，淬鍊出純白透徹的鹽晶；他們摸透了海洋深處黑潮與冷水交匯的奧秘，以六道巧奪天工的微米工序，馴服了野生魚卵的野性與腥羶，將海魚的脂膏轉化為舌尖上濃郁如流沙、黏牙而回甘的極致美味。

今天，當我們用高粱酒抹過烏魚子表面，放在藍色火苗上輕炙數秒，看著外皮起微小金黃氣泡、聞著那股焦香濃烈而深邃的海味時，我們品嚐到的，絕不僅僅是一道昂貴的年節珍餚。

那是四百年來，千千萬萬個在黑水溝驚濤駭浪中挺直脊樑的討海人，用鹽霜、海風與生命，在島嶼舌尖上烙印下的最自豪、最燦爛的金色圖騰。
