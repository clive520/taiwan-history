# 《臺灣史》專題章節標準完工檢核清單（Chapter Production Checklist SOP）

> **適用範圍**：全書六大歷史時期、共 18 個深度專題章節。  
> **執行準則**：後續每一章節製作時，必須**百分之百完成本清單中的所有項目**，並經檢核確認無誤後，方可宣告該章完工。

---

## 📋 八大階段完工檢核標準表

### 【階段一：史料考證與雙模長文完稿】
- [ ] **一手史料與坐標考證**：蒐集該時期考古挖掘報告、歷史文獻或檔案，確認精確 WGS84 經緯度坐標與地名。
- [ ] **甲部：深度歷史專題長文**：
  - 依照標準架構（引言破曉、核心風暴、歷史轉折、現代共鳴）撰寫 8,000 ~ 15,000 字考證專文。
  - **嚴格採用標準 Markdown 真實表格（Semantic Markdown Tables）**：
    - 嚴格禁止使用純文字代碼塊（` ```text `）或 ASCII 繪製框線（`┌───┬───┐`）呈現比對與結構資料。
    - 凡涉及地理生態對照、考古地層特徵、科技工藝指標、制度族群比對、科學測年翻案以及歷史大事記（Timeline），**一律使用標準 Markdown 表格語法（`| 欄位 | 欄位 |`）** 呈現。
    - 前端自動透過 `marked.js` 解析為原生 HTML `<table>` 元素，並享有現代博物館典藏級 CSS 斑馬紋、邊框、深色模式與 `overflow-x: auto` 響應式水平滾動容器保護，徹底杜絕破版與版面異常左右滑動。
  - **嚴格採用高解析度資訊圖表（Infographic Diagram Assets）替代 ASCII 關係圖**：
    - 嚴格禁止使用純文字代碼塊（` ```text `）或 ASCII 框線字符（`┌─┐`、`│`、`▼`、`──`）拼湊關係圖、戰術部署圖、科舉三級體系或物流網絡。
    - 凡涉及戰術走勢、組織架構、考選流程、轉口貿易三角網絡等視覺化示意圖，**一律以程式渲染為獨立高解析度 PNG 資訊圖表**（如 `chXX_diagram_[名稱].png`，搭配深色主題、圓角質感卡片、清晰粗黑體與精確方向箭頭），並以標準 Markdown 圖片語法置入。確保在手機、平板與桌面任何載具下皆能 100% 自適應縮放，杜絕字元折行與框線錯位。
- [ ] **乙部：影視級口播分鏡腳本**：
  - 劃分 4 大場景（破題懸念、核心現場、轉折高潮、終局迴響），精準控制在 7 ~ 8 分鐘節奏。
  - 明確標註每段場景的【畫面視覺建議】與【旁白台詞】。
- [ ] **Faster-Whisper 專用提示詞庫**：
  - 針對該章核心人名、地名、文化、器物、地質術語，建立 20+ 組繁體中文 `initial_prompt`。
- [ ] **檔案歸檔**：以 UTF-8 編碼儲存於 `[時期目錄]/第XX章_[主題]_[副標題].md`。

### 【階段二：電影級歷史概念插圖製作】
- [ ] **全章至少 3 至 4 幅高品質歷史概念復原插圖**：
  - **插圖 1（Hero Banner 精裝封面圖）**：16:9 電影級比例，重現宏大宏觀地理環境或關鍵歷史大場景。
  - **插圖 2（聚落生活現場／建築景觀復原圖）**：重現原始聚落生活、干欄式或海蝕洞穴居建築、社會互動。
  - **插圖 3（核心工藝技術／器物製作特寫圖）**：生動刻劃打製/磨製石器、玉器磨製、陶器捏製或金屬冶煉火候。
  - **插圖 4（跨海貿易遠航／生態地質現場復原圖）**：重現古生物大遷徙、黑潮遠洋航海、跨島嶼貿易圈交換現場。
- [ ] **視覺品質標準**：具備博物館典藏油畫質感、光影層次鮮明、無邊框、無現代水印文字、嚴格依循考古學與歷史學考證。
- [ ] **檔案歸檔與置入**：
  - 儲存至 `assets/images/chXX/chXX_[主題].jpg`。
  - 於文章主體 Markdown 依章節段落精準置入圖片及詳細考證圖說文字。
